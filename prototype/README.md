# Prototype de référence

Copie du prototype de Vysora (HTML, CSS et JavaScript natif, données et états simulés), reprise du dépôt `vysora` au commit `39408ff` (19 octobre 2026). Les captures d'écran (`preview/`) et les images sources non utilisées par les pages n'ont pas été copiées.

- **Lecture seule** : c'est la référence visuelle et fonctionnelle du produit. On ne le modifie pas ici ; une évolution du prototype se fait dans son dépôt, puis se recopie.
- **Le consulter** : `pnpm prototype`, puis http://localhost:5173. Le bouton « Tweaks » de chaque page permet de voir ses états (visiteur, membre, rôles, compte en lecture seule…) et ses variantes visuelles ; le produit garde les valeurs par défaut.
- **Le porter** : [`../docs/portage-prototype.md`](../docs/portage-prototype.md).
